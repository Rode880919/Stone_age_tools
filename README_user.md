# 石器时代·宠物工具箱 使用说明

本文面向打包后的 `exe` 使用者，重点说明“程序能做什么、每一页怎么填、结果怎么看”。

## 1. 启动程序

双击程序目录中的：

```text
sa_pet_assistant.exe
```

启动后，主窗口标题会显示为：

```text
石器时代·宠物工具箱
```

如果你想查看内置说明，可以从菜单进入：

- `帮助 -> 使用说明`
- `帮助 -> 宠物基础知识`

## 2. 这个工具能做什么

当前版本包含 5 个功能页：

1. 反推计算
   根据多个等级下的属性，反推宠物可能的成长率与 `INITNUM`。
2. 成长模拟
   已知 `INITNUM` 和成长率时，模拟宠物练到 140 级后的属性分布。
3. 转生模拟
   输入宠物成长、MM 成长和等级，计算转生后成长，并继续模拟到 140 级。
4. 融合成蛋
   输入主宠、副宠的成长与等级，计算融合后的蛋基础成长，以及无喂药时的孵化后成长。
5. 融合蛋喂药
   在已知蛋基础成长时，搜索喂满 40 颗药后的最优方案，并比较孵化后的成长结果。

## 3. 术语说明

为了避免看页面时混淆，先统一几个词：

- `成长率`：就是 `V / S / T / D` 这四项
- `VSTD`：四项成长率总和
- `蛋基础成长`：蛋在喂药前的面板值
- `孵化后成长`：蛋按孵化公式计算后的四项结果
- `出生后 10 点随机`：宠物出生后再额外分配的 10 点，不算在孵化后成长里

你在“融合蛋喂药”页里看到的优化结果，默认都是指：

- `孵化后成长`
- 不含出生后 10 点随机

## 4. 各页面怎么用

### 4.1 反推计算

适合场景：
你已经知道同一只宠物在多个等级下的面板属性，想反推它可能的成长率。

填写方式：

- 至少填写两行数据
- 每行填写：`等级 / HP / ATK / DEF / SPD`
- 等级不能重复
- 如果是转生宠，勾选“转生宠物”

结果怎么看：

- `Rank`：成长档位
- `VSTD`：四项成长率总和
- `成长率 V / S / T / D`：候选成长率
- `成长误差`：成长拟合误差
- `INIT残差`：对应 `INITNUM` 的残差
- `INITNUM`：候选初始值
- `置信度`：相对排序参考

适用建议：

- 等级点越多，通常反推越稳定
- 尽量使用跨度较大的等级数据
- 如果结果太多，可以再补一组等级数据继续筛

### 4.2 成长模拟

适合场景：
你已经知道宠物的 `INITNUM` 和成长率，想看它练到 140 级后大概会落在什么范围。

填写方式：

- `INITNUM`
- `V / S / T / D`
- 模拟次数

结果怎么看：

表格显示 140 级时：

- 生命
- 攻击
- 防御
- 敏捷
- 成长

每一项会显示：

- 最弱
- P5
- P25
- P50
- P75
- P95
- 最强

可以把 `P50` 理解为中位水平，把 `P5 ~ P95` 理解为大部分情况的浮动区间。

### 4.3 转生模拟

适合场景：
你想验证一只宠物在给定 MM、等级和转生次数时，转生后的成长情况。

填写方式：

- 宠物：`INITNUM / V / S / T / D`
- MM：`V / S / T / D`
- 宠物等级
- 转生次数：`第1次` 或 `第2次`
- `转生能力上限`
- 模拟次数

结果怎么看：

页面上方会显示：

- `转生能力值`
- 当前使用的 `转生能力上限`
- 新成长率
- `VSTD`
- 原 Rank
- `Fx`

下方表格则显示转生后宠物继续升到 140 级时的属性分布。

### 4.4 融合成蛋

适合场景：
你想知道某组主宠、副宠融合后，蛋面基础成长和最终孵化成长会是多少。

填写方式：

- 主宠：`等级 / V / S / T / D`
- 副宠1：`等级 / V / S / T / D`
- 副宠2：可空

说明：

- 副宠2整行留空，表示只用 1 只副宠
- 当前结果不包含融合后蛋面的 `+-2` 随机
- 当前结果不包含出生后的 10 点随机加点

结果怎么看：

页面会同时给出：

- 蛋基础成长
- 孵化后成长
- 两者各自的 `VSTD`

如果你关心后续喂药优化，通常应重点看：

- 蛋基础成长：作为喂药页输入
- 孵化后成长：作为无喂药时的基准

### 4.5 融合蛋喂药

适合场景：
你已经知道蛋基础成长，想比较不同喂药方案，找出更优的孵化后成长。

填写方式：

- 输入蛋基础成长 `V / S / T / D`
- 选择计算方式
- 保持默认规则，或手动修改规则参数
- 也可以直接手工填写自定义喂法

当前约束：

- 必须喂满 `40` 颗
- 当前页面不考虑超时衰减

两种计算方式：

1. 线性目标
   适合你已经有综合评分公式时使用。
   例如：`xV=1, xS=2, xT=0, xD=1`
2. 主目标 + 次目标
   适合你想先冲某个单项，再在并列时比较第二单项。

结果怎么看：

候选解会显示：

- 孵化后成长
- 总和
- 原始值
- 折算后
- 各维颗数
- 是否触发 `50` 压缩 / `150` 压缩
- 具体方案

你还可以：

- 点击某条候选解
- 将其自动回填到“自定义喂法”
- 再手动微调，观察结果变化

## 5. 结果口径要注意什么

### 5.1 蛋基础成长 ≠ 孵化后成长

工具里这两个值是分开的：

- 蛋基础成长：蛋面值
- 孵化后成长：按孵化公式计算后的成长档

融合蛋喂药页面优化的是：

- 孵化后成长
- 不含出生后 10 点随机加点

### 5.2 这个工具非常在意中间取整

很多地方不是简单套一个公式，而是分步骤向下取整。尤其在：

- 融合
- 药值折算
- 总和压缩
- 孵化分配

如果你自己手算时和工具差一点，通常先检查是不是中间步骤取整时机不同。

## 6. 你最常会用到的组合

常见流程 1：反推宠物成长

1. 在“反推计算”页输入多个等级数据
2. 选出最可信的成长率和 `INITNUM`
3. 到“成长模拟”页验证 140 级分布

常见流程 2：研究转生

1. 在“转生模拟”页输入宠物成长、MM 和等级
2. 观察新成长率与 `VSTD`
3. 再看转生后 140 级的分位数结果

常见流程 3：研究融合蛋

1. 在“融合成蛋”页算出蛋基础成长
2. 把蛋基础成长带到“融合蛋喂药”页
3. 搜索最优喂法并比较孵化后成长
